## B3. Performance: R12, менее 2 секунд

1. Откройте Chrome DevTools → Network, установите Disable cache и Fast 4G.
2. Используйте одинаковые viewport, сеть и компьютер. Запишите условия.
3. Перезагрузите Menu три раза; для Cart сначала добавьте товар, перейдите
   на #cart и также выполните три полных перезагрузки.
4. После каждого запуска сохраните скриншот Network. Запишите Load и Finish;
   отдельно укажите момент, когда меню/корзина готовы к использованию.
5. Среднее = (run1 + run2 + run3) / 3. Сравните с исходным R12, не меняя порог.

## R15: доступность не менее 99%

Docker restart и /api/health помогают восстановлению и мониторингу, но
не доказывают uptime. Нужен период наблюдения, например 7 дней, запрос
health раз в минуту и доля успешных ответов. Не записывайте 99% без измерений.
